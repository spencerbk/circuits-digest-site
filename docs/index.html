  • Espressif Launches ESP-Mosaico, Bringing AI Coding Beyond the Boundaries of Hardware
    espressif · 2026-10-20 07:03 UTC

    Shanghai, China Espressif Systems (688018.SH) today announced ESP-Mosaico, a modular development platform designed for AI-assisted hardware creation. ESP-Mosaico allows creators to combine functional modules and multiple devices while enabling Coding Agents to understand the current hardware configuration and participate directly in application development. ESP-Mosaico supports two complementary development approaches. Chat Coding lets creators start from a natural-language request and quickly build working hardware prototypes without setting up a local development environment. Vibe Coding brings AI Agents deeper into the engineering workflow, including implementation, deployment, testing on physical hardware, and continuous iteration. Software can now be generated and modified rapidly with AI, but hardware is still often constrained by fixed boards, interfaces, and product forms. ESP-Mosaico is designed to make hardware equally extensible: capabilities can be added as ideas evolve, without requiring creators to define the final form of a device from the outset. The name Mosaico, meaning “mosaic,” reflects this concept—individual hardware building blocks can be combined to create something larger and continuously evolving. Modular Hardware That Grows with the Application At the center of ESP-Mosaico is a compact standalone host featuring a 480 × 480 OLED touchscreen, haptic feedback, a built-in battery, USB Type-C connectivity, and expansion I/O. The host is powered by Espressif’s ESP32-S31, a RISC-V SoC running at up to 320 MHz, with 512 KB SRAM and support for up to 32 MB of high-speed DDR PSRAM. ESP32-S31 also integrates Wi-Fi 6, dual-mode Bluetooth 5.4, and 802.15.4, and supports interfaces including 1 Gbps Ethernet, USB 2.0 High-Speed OTG, hardware JPEG encoding and decoding, and DVP camera input. ESP-Mosaico extends these capabilities through modular hardware for functions such as cameras, sensors, buttons, lighting, and motors. Supported modules can be automatically identified and integrated by the system, reducing the need to repeatedly handle wiring and low-level driver adaptation. Composability also extends across devices. Multiple ESP-Mosaico hosts can recognize their relative position and orientation and synchronize application state wirelessly, allowing devices to be joined, separated, or rearranged as part of the application itself. This enables experiences ranging from cross-screen games to modular information displays and other multi-screen applications. Bringing AI Agents into Real-World Development Chat Coding: From an Idea to a Working Prototype For creators new to programming or AI-assisted development, ESP-Mosaico provides Chat Coding through ESP-Claw, the Coding Agent built into the platform. Creators simply describe what they want to build. ESP-Claw uses the capabilities of the connected ESP-Mosaico hardware to generate, build, and deploy the application. Development does not require a locally configured toolchain, while application interfaces, logic, and peripheral control that do not depend on online services run locally on the device after deployment. Creators can then continue refining the application conversationally—for example, adding functionality, changing behavior, or improving the user interface—turning an initial idea into an interactive hardware prototype through successive iterations. ESP-Mosaico also connects to Skills Lab, where device applications can be packaged as reusable Skills containing Lua scripts, assets, and peripheral dependencies. Creators can install existing Skills, customize supported applications, or publish their own Skills for others to use. Vibe Coding: Iterating Directly on Real Hardware ESP-Mosaico is supported on ESP ZeroCode AI platform including its complete board and peripheral simulation. You can find various ESP-Mosaico community projects here. For more advanced development, ESP-Mosaico is designed to bring other coding agents into the complete build-test-debug loop. The platform provides: Specification-driven UI development, giving Agents defined design rules, components, resources, and constraints. ESP-GSP, an AI-oriented UI framework, where interfaces can be represented using structured JSON, validated during build, simulated on a PC, and then deployed to ESP32 hardware. Closed-loop device debugging, exposing flashing, device control, inputs, UI state, performance data, and fault information through unified interfaces so Agents can analyze results and iterate. Agent-ready development resources, including BSPs, SDKs, schematics, reference projects, documentation, and Agent References. Together, these capabilities allow an Agent to repeatedly modify code, build and deploy, test on real hardware, analyze feedback, and refine the application, while developers define the goals, constraints, and acceptance criteria. Built on the Open ESP Development Ecosystem AI-generated code still depends on a strong engineering foundation to run reliably on physical hardware. ESP-Mosaico builds on Espressif’s established development ecosystem, including ESP-IDF, drivers and components, technical documentation, development and debugging tools, ESP Component Registry, and community projects. More than 200,000 projects related to ESP32 and ESP8266 are available on GitHub, along with more than 300 books published in over 10 languages. These resources can provide Coding Agents with engineering context, reference implementations, and proven development practices. By connecting these open engineering resources with direct feedback from physical devices, ESP-Mosaico provides a foundation for AI-assisted hardware development that Agents can not only reference, but also build against and validate on real hardware. Bring Ideas Beyond the Screen Whether starting with Chat Coding or using Vibe Coding for deeper product development, ESP-Mosaico enables creators to move from an idea to a working physical device—and continue evolving it through software, hardware, and AI-assisted iteration. Developers can visit the ESP-Mosaico website to learn more about the product and access development resources, or share applications with other users through Skills Lab. The ESP-Mosaico development kit is now available for purchase. For additional product information, please contact the Espressif customer support team. From natural-language creation to Agent-driven development, and from modular hardware to multi-device applications, ESP-Mosaico brings AI coding beyond the screen and into the physical world.
