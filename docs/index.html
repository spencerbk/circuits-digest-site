    Guangzhou-based HackerGadgets has launched a 4-in-1 Raspberry Pi HAT that offers RTL-SDR and LoRa connectivity, GPS and Beidou/GLONASS GNSS, and a PCF85063A real-time clock (RTC). The SDR part is implemented through an RTL2832U+R860 combo supporting 100 kHz to 1.74 GHz frequency and 100 kHz-28.8 MHz HF direct sampling. Users can select between U.FL and SMA versions depending on the type of antennas they plan to use.
