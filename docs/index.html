    The open-source Tessera project enables neat dashboards for Home Assistant on affordable 2.8-inch to 10.1-inch ESP32 touchscreen (development) kits from CYD, Guition, and Waveshare. The Tessera firmware adds a layer to ESPHome firmware for display management, touchscreen handling, dashboard rendering, tiles, plugins, and more. It works in conjunction with the Tessera Screen Manager, which provides the Home Assistant interface to configure screens, manage layouts, install firmware, and push updates. The whole solution is supposed to be easy to use thanks to a drag-and-drop editor, and users don’t need to know anything about YAML or MQTT.     cnx-software · 2026-11-23 08:00 UTC

    InMachines Ingrassia GmbH has launched the Piccola CNC, an open-source hardware desktop CNC milling machine designed for PCB prototyping and machining wood, plastics, and soft metals such as aluminum, brass, and copper. Built in Germany, the machine features a 150 × 150 × 70 mm work area, belt-driven ball screws on all three axes, ER11 collets, and a choice of 100W or 200W spindles. The machine comes in three versions, which include the Basic, Pro, and Ultimate. The Pro variant adds a full enclosure and safety interlocks, while the Ultimate model further adds a brushless spindle and laser distance sensor. Other features include USB-C and Wi-Fi connectivity, built-in CAM software for PCB, 2D, 3D, and rotary milling, and laser-based PCB height mapping on the Ultimate, with the sensor available as an accessory for Basic and Pro.
