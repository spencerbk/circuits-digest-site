  • Raspberry Pi SBCs get an open-source hardware I2C TPM 2.0 security module (Crowdfunding)
    cnx-software · 2026-11-19 09:43 UTC

    ANAVI I2C TPM 2.0 is an open-source hardware I2C TPM 2.0 security module for Raspberry Pi single board computers based on the Infineon Optiga SLB 9673 TPM 2.0 chip. It’s an alternative to the earlier ANAVI TPM 2.0 module using an Optiga SLB 9672 SPI chip. The add-on board is designed for developers, hobbyists, and professionals who require enhanced security for Raspberry Pi-based projects. It’s especially useful for disk encryption, secure key storage, and cryptographic operations, but can also work as a True Hardware Random Number Generator (TRNG) for security-critical applications.
