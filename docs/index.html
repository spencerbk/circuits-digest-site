  • usb-rea generates a Linux driver for your Windows-only USB gadget
    cnx-software · 2026-11-27 08:02 UTC

    usb-rea is an MIT-licensed tool for people who own a USB gadget that only ships with a Windows program. It captures packets while you use the Windows app and generates a pyusb driver for Linux. Many years ago, I had to reverse-engineer a USB video capture card, whose vendor didn’t want to work with a company specializing in “small-volume production”. I had to capture the packets with Wireshark and manually implement code to replay URB (USB Request Block) packets using libusb, while paying close attention to timings. A tool like usb-rea would have been useful at the time. More specifically, usb-rea captures USB traffic with USBPcap or usbmon while the user clicks through the vendor app and labels the actions. The open-source program then infers the command structure (constants, counters, value fields, lookup tables, CRCs) and writes a Markdown protocol report plus a standalone Linux driver.
